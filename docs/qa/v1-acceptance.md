# 小楠子爱旅行首版验收清单

## 自动检查

在仓库根目录运行：

```bash
cd backend
.venv/bin/python manage.py test -v 2
.venv/bin/python manage.py check
cd ..
node --test miniprogram/tests/*.test.js
bash deploy/tests/test_deploy_files.sh
git diff --check
```

## 内容发布闭环

- [ ] 后台新建草稿产品时，公开 API 不返回该产品。
- [ ] 草稿填写封面、亮点、团期、行程和提醒后可以进入审核。
- [ ] “发布所选产品”先显示二次确认页。
- [ ] 确认发布后，首页和列表 API 返回该产品。
- [ ] 小程序首页可以进入列表、详情和公众号咨询页。
- [ ] 下架产品后，列表和详情 API 均不再返回该产品，后台内容仍保留。
- [ ] 签约中的两个供应商产品始终保持草稿。

## 页面与异常路径

- [ ] 首页没有产品时显示准备中的空状态，不展示北极或南非空栏目。
- [ ] 断网、接口超时和服务器异常均显示可重试的中文提示。
- [ ] 不存在或未发布的产品详情显示“产品不存在或尚未发布”。
- [ ] 图片加载失败不影响标题、行程和咨询入口使用。
- [ ] 找搭子与 AI 旅行顾问均显示“功能开发中，敬请期待”。
- [ ] 消息页显示建设中提示。
- [ ] 我的页面不要求登录。
- [ ] 公众号组件加载失败时，公众号名称、搜索指引和复制话术仍可用。
- [ ] 后台登录失效后回到登录页，不暴露后台内容。

## 合规边界

- [ ] 页面没有购买、下单、支付、定金或签署合同入口。
- [ ] 页面不显示数值价格，只使用“价格咨询”。
- [ ] 页面不收集手机号，不创建咨询表单或咨询单。
- [ ] 页面不宣称普通按钮必然打开公众号聊天。
- [ ] 产品经营及服务主体信息经过上线前人工复核。
- [ ] 用户协议、隐私政策和备案信息使用最终审核文本。

## 服务器上线验证

- [ ] 旧 `/opt/nanzi-ai`、systemd 和 Nginx 配置已经完整归档并验证可读取。
- [ ] `api.nanzitravel.com` 与 `admin.nanzitravel.com` 证书有效。
- [ ] 5000 和 8001 均未向公网开放。
- [ ] `https://api.nanzitravel.com/healthz` 返回 `{"status":"ok"}`。
- [ ] 后台仅通过 HTTPS 访问。
- [ ] 每日备份任务成功生成并验证归档。
- [ ] 完成一次应用版本回滚演练。
