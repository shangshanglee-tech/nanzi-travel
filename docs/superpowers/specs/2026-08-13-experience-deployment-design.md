# 小楠子爱旅行体验版部署设计

- 记录日期：2026-08-13
- 关联基线：`2026-08-12-mini-program-design.md` v0.2
- 状态：已确认，待执行

## 目标

将已授权的 HX 南极产品内容导入小程序正式内容库，并发布微信小程序体验版，供管理员及已添加的体验成员使用。体验版只用于内部查看和验收，不提交微信审核、不对公众发布。

## 本次范围

1. 将 11 条已抓取的 HX 南极线路转换为后台的标准产品数据，并以“已发布”状态导入。
2. 以独立服务部署小程序 API 与管理后台，开放 `api.nanzitravel.com` 和 `admin.nanzitravel.com` 的 HTTPS 访问。
3. 将小程序的正式 API 地址切换为该 API 域名，并完成微信公众平台的合法域名配置。
4. 使用微信开发者工具上传体验版，生成体验二维码；管理员和已添加的体验成员可扫描查看。

## 明确不在范围内

- 不提交审核、不发布正式版；
- 不开放支付、订单、合同、用户登录、真实找搭子、消息或面向用户的 AI；
- 不删除、停止、迁移或改写现有 `/opt/nanzi-ai` 服务；
- 不将产品售价或库存作为体验版公开内容。

## 部署与隔离

新服务使用独立目录、独立运行账户、独立数据库与独立 systemd 服务，例如 `nanzi-travel-api.service`。Nginx 仅将新 API 和后台域名反向代理至新服务的本机端口；历史 AI 服务维持原状。

现有初始化脚本包含“归档并关闭旧服务”的步骤，因此本次不直接执行该脚本。若服务器上缺少运行账户、Nginx 站点、证书或目录，将仅补充这些新服务所需的隔离配置；任何会改变旧 AI 服务运行状态的操作都必须另行确认。

## 内容导入

导入程序将 H5 中的 HX 路线资料映射为后台的产品、团期、行程日和图片记录：

- 产品标题、简介、天数、线路亮点、船只、出发地与注意事项；
- 已抓取的多个团期和每日行程；
- 已下载封面图与授权图片的可访问媒体地址；
- 价格字段保持为空，咨询状态统一为“咨询获取最新方案”。

导入前先做格式和必填字段校验；导入以 `slug` 幂等更新，避免重复创建。导入完成后抽查首页、列表、11 条详情、团期与咨询页。

## 微信体验版流程

小程序 API 域名配置完成并生效后，在微信开发者工具中用现有 AppID 上传体验版。微信管理员在公众平台查看生成的体验二维码；已添加的体验成员可在微信中扫码进入。本步骤需要已登录并具有该小程序管理权限的微信开发者工具账号，二维码由微信平台生成，不由服务器生成。

## 验收与回退

验收条件：HTTPS 健康检查和首页接口正常；后台可登录；小程序首页、产品列表、每条产品详情、团期、公众号咨询引导均可用；体验成员可扫码访问。

如发布后出现问题，先将小程序体验版回退到上一上传版本；服务端保留部署前备份，可回退独立服务代码与数据库。本次不会把旧 AI 服务作为回退路径或变更对象。
