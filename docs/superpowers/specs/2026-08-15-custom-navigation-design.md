# 自定义小程序顶部导航设计

## 目标

移除微信默认导航栏中固定显示的“小楠子爱旅行”，让页面顶部符合内容杂志式视觉，同时保留清晰、可靠的返回路径。

## 范围

- 全局设置 `navigationStyle: "custom"`，不再使用微信默认标题栏。
- 首页不额外显示标题栏，保留既有内容顶部。
- 非首页页面使用统一的自定义顶部栏：左侧返回按钮、居中页面标题、右侧为微信胶囊按钮预留安全区。
- 不改变页面数据、底部 Tab、接口或咨询流程。

## 交互与适配

- 返回按钮调用 `wx.navigateBack`；没有历史页面时回到首页。
- 标题由各页面传入，避免显示统一品牌名。
- 顶部栏按状态栏和胶囊按钮信息计算安全间距，避免遮挡系统控件。
- 视觉采用现有深绿、米白和低圆角体系。

## 验收

- 首页顶部不出现“小楠子爱旅行”。
- 产品、船只、消息、我的及静态说明页可正常返回。
- iOS 与 Android 的顶部内容均不与胶囊按钮重叠。
