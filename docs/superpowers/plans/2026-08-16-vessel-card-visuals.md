# 船只卡片视觉资产

## 目标

为船只增加独立于详情页封面图的「卡片图」与「卡片底色」，先配置阿蒙森号。

## 方案

1. 在 `Vessel` 增加可选 `card_image`、`card_tone` 字段，并生成迁移。
2. 公开 API 返回两个字段；详情页原有 `hero_image` 保持不变。
3. Django 后台增加独立的「首页卡片展示」区块，方便电脑端人工编辑。
4. 随代码带入用户导出的阿蒙森号 WebP，并提供幂等导入命令，把它复制进线上媒体库、写入 `#071A32`。
5. 用模型、API 和导入命令测试覆盖该契约，再运行全量测试。

## 发布

代码发布后，在服务器执行新的导入命令；小程序随后可使用返回的卡片资产进行视觉卡片改造。
